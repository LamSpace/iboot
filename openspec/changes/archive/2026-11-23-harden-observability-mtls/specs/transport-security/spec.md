# Spec Delta

## MODIFIED Requirements

### Requirement: 证书过期有自动门禁

证书生命周期 SHALL 被回归检查覆盖，避免本地环境在证书过期后突然整体不可用。

- 回归检查 MUST 计算叶子证书的剩余有效期。
- 剩余有效期小于 30 天时，检查 MUST 失败并指出证书路径与到期时间。
- 检查失败 MUST 阻止把环境判定为可验收。
- 轮换 MUST 有可重复入口：检查、按需重签、重启依赖组件。
- 重签 MUST 显式触发，MUST NOT 在普通启动中自动执行。
- 轮换后 MUST 能通过同一检查，并保留 CA 与既有信任库。

#### Scenario: 证书即将过期时失败

- **WHEN** 叶子证书剩余有效期小于 30 天
- **THEN** 回归检查失败并给出生效日期
- **AND** 提示执行重签命令

#### Scenario: 证书有效时通过

- **WHEN** 叶子证书剩余有效期不少于 30 天
- **THEN** 检查通过

#### Scenario: 按需轮换

- **WHEN** 执行轮换脚本并显式允许重签
- **THEN** 叶子证书重新签发
- **AND** 再次检查通过

#### Scenario: 普通启动不重签

- **WHEN** 未显式要求重签
- **THEN** 轮换脚本只检查并报告
- **AND** 不修改证书文件
