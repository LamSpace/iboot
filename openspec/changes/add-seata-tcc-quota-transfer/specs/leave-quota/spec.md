# Spec Delta

## ADDED Requirements

### Requirement: 额度冻结

系统 SHALL 在额度行上维护冻结次数，用于 TCC 预占。冻结 MUST 在剩余额度（总额度减已用减冻结）足够时原子增加；不足时 MUST 失败且不改变任何额度。冻结次数 MUST NOT 为负。

#### Scenario: 冻结成功

- **WHEN** 用户剩余额度不少于申请冻结的次数
- **THEN** 冻结次数原子增加对应次数
- **AND** 已用次数与总额度不变

#### Scenario: 冻结不足

- **WHEN** 用户剩余额度少于申请冻结的次数
- **THEN** 冻结失败并返回明确错误
- **AND** 冻结与已用次数均不变化

#### Scenario: 冻结不出现负数

- **WHEN** 对同一用户重复执行释放
- **THEN** 冻结次数不会低于 0

### Requirement: 冻结释放与划转确认

系统 SHALL 在取消时释放冻结，在确认时释放冻结并调整相关用户的总额度。确认与释放 MUST 幂等，重复执行不得重复加减。

#### Scenario: 取消释放

- **WHEN** 划转被取消
- **THEN** 划出方的冻结次数减少对应次数
- **AND** 双方的总额度不变

#### Scenario: 确认划转

- **WHEN** 划转被确认
- **THEN** 划出方冻结减少、总额度减少对应次数
- **AND** 划入方总额度增加对应次数

#### Scenario: 重复确认

- **WHEN** 同一划转被重复确认
- **THEN** 额度只调整一次
- **AND** 返回成功
