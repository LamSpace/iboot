# api-gateway Specification

## Purpose

为前端提供唯一访问入口，使后端接口在服务之间迁移时前端无需改动，并在入口处统一承担跨域、限流与上游故障的响应约定。

## Requirements

### Requirement: 唯一入口且路径不变

前端 MUST 只通过网关访问后端；网关转发后，后端收到的路径、查询参数与请求头 MUST 与前端发出时一致（仅按既定前缀规则改写）。

- 前端使用的路径前缀、接口路径与查询参数 MUST NOT 因引入网关而改变。
- 后端返回的响应体结构 MUST NOT 因经过网关而改变。
- 网关 MUST NOT 修改请求方法、请求体或响应状态码。

#### Scenario: 既有接口经网关访问结果不变
- **WHEN** 前端通过网关请求任一既有接口
- **THEN** 返回的状态码、响应体结构与直接访问后端时一致
- **AND** 后端收到的路径与查询参数与前端发出时一致

#### Scenario: 两个后端前缀各自转发
- **WHEN** 前端请求以管理端前缀发起
- **THEN** 请求被转发到管理端服务
- **WHEN** 前端请求以 AI 前缀发起
- **THEN** 请求被转发到 AI 服务且路径按既定规则改写

### Requirement: 接口归属唯一且可判定

网关路由 MUST 保证任意一条接口路径只解析到一个服务。

- 路由匹配 MUST 遵循「更具体的前缀优先」，兜底前缀排在最后。
- 系统 MUST 能在构建期判定是否存在未被任何路由覆盖的接口路径，或同一条路径被两条规则同时匹配。
- 出现上述任一情况时，检查 MUST 以失败结束，不得仅告警。

#### Scenario: 具体前缀优先于兜底前缀
- **WHEN** 一条路径同时匹配具体前缀规则与兜底规则
- **THEN** 请求被转发到具体前缀规则指向的服务

#### Scenario: 未覆盖路径被检查发现
- **WHEN** 某接口路径不属于任何路由规则
- **THEN** 路由覆盖检查失败并指出该路径

#### Scenario: 重复归属被检查发现
- **WHEN** 同一路径被两条规则同时匹配且无法判定优先级
- **THEN** 路由覆盖检查失败并指出冲突的两条规则

### Requirement: 长连接推送原样透传

网关 MUST 支持服务端推送长连接，不得缓冲、截断或主动终止。

- 长连接上的响应 MUST 在产生时立即送达客户端，不得等到缓冲区填满。
- 客户端以查询参数携带凭证的长连接请求 MUST 被原样转发，网关 MUST NOT 剥离该参数。
- 网关 MUST NOT 对长连接施加短于业务心跳周期的空闲超时。

#### Scenario: 推送事件实时到达
- **WHEN** 客户端经网关建立推送长连接后，后端产生一条推送事件
- **THEN** 客户端在秒级内收到该事件

#### Scenario: 查询参数凭证被保留
- **WHEN** 客户端以查询参数携带凭证请求推送通道
- **THEN** 后端能读到该凭证并据此完成鉴权

#### Scenario: 长连接不被空闲超时切断
- **WHEN** 长连接在心跳周期内保持空闲
- **THEN** 连接不被网关主动关闭

### Requirement: 跨域在入口统一处理

跨域 MUST 由网关统一处理，后端服务 MUST NOT 需要各自维护跨域配置。

- 预检请求 MUST 由网关直接响应，不转发到后端。
- 允许的来源、方法与请求头 MUST 由统一配置决定，不得逐服务分散配置。

#### Scenario: 预检请求由网关响应
- **WHEN** 浏览器发起跨域预检请求
- **THEN** 网关返回允许的跨域响应头
- **AND** 该请求不被转发到后端服务

#### Scenario: 实际请求携带跨域响应头
- **WHEN** 浏览器发起跨域实际请求并经过网关
- **THEN** 响应中包含与统一配置一致的跨域响应头

### Requirement: 上游不可用时快速失败且不雪崩

当某个后端服务不可用或响应过慢时，网关 MUST 快速返回可辨识的失败响应，不得无限等待，也不得把故障扩散到其它服务。

- 上游不可用 MUST 返回服务不可用类状态码，响应体 MUST 能区分「上游不可用」与「请求本身有误」。
- 超时 MUST 有明确上限，不得让请求一直挂起。
- 单个服务故障 MUST NOT 影响其它服务的正常请求。

#### Scenario: 后端停机时返回明确失败
- **WHEN** 某后端服务已停止，前端经网关请求该服务的接口
- **THEN** 网关在有限时间内返回服务不可用类状态码
- **AND** 响应体表明是上游不可用

#### Scenario: 单个服务故障不影响其它服务
- **WHEN** 某后端服务不可用
- **THEN** 指向其它服务的请求仍然正常返回

### Requirement: 入口限流

网关 MUST 能在入口按统一规则限制请求速率，保护后端不被突发流量压垮。

- 被限流的请求 MUST 返回明确的限流状态码，响应体 MUST 表明是限流而非业务错误。
- 限流规则 MUST 可在运行期调整并生效，无需重启网关。

#### Scenario: 超过阈值被限流
- **WHEN** 某来源在窗口期内的请求数超过配置阈值
- **THEN** 超出部分返回限流状态码
- **AND** 响应体表明是限流

#### Scenario: 规则调整后即时生效
- **WHEN** 限流阈值被下调
- **THEN** 后续请求按新阈值被限流，且网关未重启
