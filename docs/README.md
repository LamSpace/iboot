## 项目结构

```
iboot/
├── pom.xml                  # 父 POM，聚合 12 个后端模块
├── docker/                  # Compose 编排、镜像模板与中间件配置
├── scripts/                 # 开发、部署与回归脚本
├── docs/                    # 本文档目录
├── openspec/                # 能力契约与变更记录
├── iboot-kernel/            # 共享内核库，不独立部署
├── iboot-db-init/           # 建库与集中式迁移，运行后退出
├── iboot-system/            # 系统域 :8080
├── iboot-ai/                # AI 工作台 :8081
├── iboot-file/              # 文件服务 :8082
├── iboot-auth/              # 认证服务 :8083
├── iboot-notify/            # 消息与通知 :8084
├── iboot-job/               # 调度与备份 :8085
├── iboot-workflow/          # 审批工作流 :8086
├── iboot-monitor/           # 监控与日志 :8087
├── iboot-gateway/           # 网关 :8088
├── iboot-ops/               # 运维控制台 :8089
└── iboot-portal/            # 前端（Vue 3 + Vite）
```

## 启动入口

```bash
# 本地开发：中间件 → db-init → 九个业务服务与运维控制台
scripts/dev-init.sh

# 同时启动前端开发服务器
scripts/dev-init.sh --frontend

# 全栈容器化（构建 + Compose + 健康检查）
scripts/docker-deploy.sh up
```

前端依赖安装使用 `cnpm`，API 基址为 `/iboot/api`，开发端口为 `3000`；完整说明见
[05-快速开始](./05-快速开始.md)。容器部署的权威说明见 [`docker/README.md`](../docker/README.md)。
